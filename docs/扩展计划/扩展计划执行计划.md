## 本次对话完成的工作（2026-08-01）

### 日志库 (lg) 架构简化
- `Logger.writerSrc` 字段：子 Logger 持有 `defaultLogger` 指针，log 时动态读取最新 writer
- `SetDefaultWriter(w)`：只修改 `defaultLogger.writer` 字段，子 Logger 自动跟随
- `SetPath` 分级配置修复：不再创建根目录汇总文件，避免 INFO 日志重复出现

### TUI 层优化
- **光标修复**：`fullRender`/`diffRender` 末尾改用 `CursorBack(len(line) - curCol)` 替代 `CursorForward(curCol)`
- **Markdown 渲染**：修复 `### 标题` 前缀未去除的 bug；每行通过 `MarkdownLine` 转换裸 Markdown 为 ANSI 样式
- **去掉重复回显**：删除 `renderUserBox`，LineEditor 实时回显作为唯一显示
- **去掉背景色**：AI 回复无背景色，简洁输出
- **流式输出**：保持流式打字机效果，每行实时输出
- **行间隔**：回复前后留空行，工具调用/结果/tokens 缩进 2 空格对齐

### 文案修正
- `"Pi Agent"` → `"Pi-Go Agent"`（欢迎语、system prompt、help 输出）
