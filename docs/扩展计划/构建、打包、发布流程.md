# 构建、打包、发布流程

## 概述

企业级但轻量的构建-打包-发布方案，通过 Git Tag 触发，自动交叉编译 + GitHub Release。

---

## 一、版本策略

[Semantic Versioning](https://semver.org/)：`v1.0.0` → `v1.1.0`（功能） → `v1.1.1`（修复）

---

## 二、构建方案

### 2.1 平台矩阵

| OS | Arch | 说明 |
|----|------|------|
| darwin | arm64 | Apple Silicon Mac ✅ |
| windows | amd64 | Windows 桌面 ✅ |

> 文档保留全平台参考：`linux/amd64` `linux/arm64` `darwin/amd64` 按需扩展。

### 2.2 ldflags 注入

编译时注入版本元信息：

```bash
go build -ldflags "
    -s -w
    -X main.version=v1.0.0
    -X main.commit=$(git rev-parse --short HEAD)
    -X main.buildDate=$(date -u +%Y-%m-%dT%H:%M:%SZ)
" -o pg ./cmd/pg/
```

`pg version` 输出：

```
pg version v1.0.0
  commit:    abc1234
  built:     2026-08-01T12:00:00Z
  go:        go1.26.5
```

`cmd/pg/main.go` 中 `version`/`commit`/`buildDate` 是 `var`（非 `const`），默认值 `"dev"`/`"none"`。

### 2.3 产物命名

```
pg_1.0.0_darwin_arm64.tar.gz
pg_1.0.0_windows_amd64.zip
```

## 三、新增文件

### 3.1 `.goreleaser.yaml`

goreleaser 配置，核心内容：

- `builds.goos: [darwin, windows]`，`goarch: [amd64, arm64]`，`ignore` 排除 `darwin/amd64` 和 `windows/arm64`
- `ldflags: -s -w -X main.version={{.Version}} ...`
- `archives` 打包 tar.gz/zip，附带 LICENSE
- `checksums.txt` 校验文件
- `changelog` 自动从 commit 生成（排除 docs/test/ci）

### 3.2 `.github/workflows/release.yml`

```yaml
name: Release
on: push: { tags: ['v*'] }
jobs:
  goreleaser:
    steps:
      - checkout + setup-go
      - goreleaser/goreleaser-action@v6 (args: release --clean)
```

### 3.3 `LICENSE`

MIT 许可证。

### 3.4 `install.sh`

自动检测 OS/Arch，从 GitHub Releases 下载预编译二进制到 `$GOPATH/bin`。

```bash
curl -fsSL https://raw.githubusercontent.com/Effortful-lion/pi-go/main/install.sh | bash
```

## 四、发布流程

```bash
# 1. 更新版本号（cmd/pg/main.go 中 version var，或 goreleaser 通过 tag 注入）
git tag v1.0.0

# 2. 推送 tag，CI 自动构建+发布
git push origin main --tags
```

GitHub Actions 自动执行：

```
Tag 推送
  └─ Release Job:
       ├─ goreleaser 交叉编译 2 平台
       ├─ 打包 tar.gz/zip + checksums.txt
       ├─ 创建 GitHub Release（含自动 changelog）
       └─ 上传构建产物
```
