## Terminal 层：驯服终端

### 1. 原始模式（Raw Mode）

正常终端是 **cooked mode**（熟模式）：操作系统缓冲你的输入，按 Enter 才发送给程序，回显每个字符。

原始模式（raw mode）让我们直接读取每次按键，实现"实时"交互：

```go
func EnterRawMode() (*RawState, error) {
    fd := int(os.Stdin.Fd())
    oldState, err := termiosGet(fd)  // 保存当前状态
    newState := *oldState
    // 关闭回显、规范模式、信号处理
    newState.Lflag &^= syscall.ECHO | syscall.ICANON | syscall.ISIG
    newState.Cc[syscall.VMIN] = 1     // 每次读 1 字节
    newState.Cc[syscall.VTIME] = 0    // 不等待
    termiosSet(fd, &newState)
    return &RawState{fd: fd, oldState: oldState}, nil
}
```

在 raw mode 下，程序能用 `os.Stdin.Read([]byte{0})` 逐个字节读取按键。

**关键决策**：为什么用 `syscall` + `termios` 而不是第三方库？
→ 这是与操作系统底层交互的最直接方式，代码量很小（~30 行），不需要引入一个完整库做这么简单的事。

### 2. ANSI Escape Codes：控制终端的"魔法咒语"

终端本质上是一个字符网格（如 80 列 × 24 行）。ANSI escape codes 是通过特殊字符序列控制光标位置、颜色等。

```go
// 光标控制
CursorUp(n)       → "\033[nA"   上移 n 行
CursorDown(n)     → "\033[nB"   下移 n 行
CursorForward(n)  → "\033[nC"   右移 n 列
CursorBack(n)     → "\033[nD"   左移 n 列
CursorMoveTo(r,c) → "\033[r;cH" 跳到第 r 行第 c 列
HideCursor()       → "\033[?25l" 隐藏光标
ShowCursor()       → "\033[?25h" 显示光标

// 屏幕控制
ClearScreen()      → "\033[2J"   清屏
ClearLine()        → "\033[2K"   清除当前行
ClearLineFromCursor() → "\033[0K" 清除光标到行尾

// 颜色样式
"\033[31m"  → 红色前景色
"\033[1m"   → 加粗
"\033[0m"   → 重置所有样式
```

### 3. 颜色系统

```go
type Color int

const (
    ColorDefault Color = 0
    ColorBlack   Color = 30
    ColorRed     Color = 31
    ColorGreen   Color = 32
    ColorYellow  Color = 33
    ColorBlue    Color = 34
    ColorMagenta Color = 35
    ColorCyan    Color = 36
    ColorWhite   Color = 37
    ColorGray    Color = 90
)

type Style struct {
    Fg       Color  // 前景色
    Bold     bool
    Dim      bool
    Italic   bool
    Underline bool
}

func StyleText(text string, style Style) string {
    // 构建: "\033[1;31mtext\033[0m"
    codes := []string{}
    if style.Bold { codes = append(codes, "1") }
    if style.Dim  { codes = append(codes, "2") }
    if style.Fg != ColorDefault { codes = append(codes, strconv.Itoa(int(style.Fg))) }
    return "\033[" + strings.Join(codes, ";") + "m" + text + "\033[0m"
}

// 便捷函数
func Bold(text string) string  { return StyleText(text, Style{Bold: true}) }
func Red(text string) string   { return StyleText(text, Style{Fg: ColorRed}) }
func Green(text string) string { return StyleText(text, Style{Fg: ColorGreen}) }
func Blue(text string) string  { return StyleText(text, Style{Fg: ColorBlue}) }
func Cyan(text string) string  { return StyleText(text, Style{Fg: ColorCyan}) }
func Gray(text string) string  { return StyleText(text, Style{Fg: ColorGray}) }
func Yellow(text string) string { return StyleText(text, Style{Fg: ColorYellow}) }
```

**关键决策**：`Style` 是可组合的，但 `Bold()` 等便捷函数只做一件事。API 设计成渐进式的：简单场景用便捷函数，复杂场景用 `StyleText`。

### 4. 行编辑：EditLine

实现一个类似 `readline` 的单行编辑功能：

```go
func EditLine(prompt string, initial string) (string, bool, error) {
    // 进入 raw mode
    raw, _ := EnterRawMode()
    defer raw.Restore()

    line := []rune(initial)
    cursor := len(line)

    fmt.Print(prompt)
    renderLine(prompt, line, cursor)

    for {
        key := readKey()
        switch key {
        case EnterKey:
            fmt.Println()
            return string(line), true, nil
        case CtrlCKey, CtrlDKey:
            return "", false, nil  // 取消
        case LeftKey:
            if cursor > 0 { cursor-- }
        case RightKey:
            if cursor < len(line) { cursor++ }
        case HomeKey:
            cursor = 0
        case EndKey:
            cursor = len(line)
        case BackspaceKey:
            if cursor > 0 {
                line = append(line[:cursor-1], line[cursor:]...)
                cursor--
            }
        case DeleteKey:
            if cursor < len(line) {
                line = append(line[:cursor], line[cursor+1:]...)
            }
        case CtrlLeftKey:
            for cursor > 0 && line[cursor-1] == ' ' { cursor-- }
            for cursor > 0 && line[cursor-1] != ' ' { cursor-- }
        case CtrlRightKey:
            for cursor < len(line) && line[cursor] != ' ' { cursor++ }
            for cursor < len(line) && line[cursor] == ' ' { cursor++ }
        default:
            if key >= 32 {  // 可打印字符
                line = append(line[:cursor], append([]rune{rune(key)}, line[cursor:]...)...)
                cursor++
            }
        }
        renderLine(prompt, line, cursor)
    }
}
```

**关键设计**：`EditLine` 是一个阻塞函数——调用后会等待用户输入完成（Enter 或 Ctrl+C），期间通过 `readKey()` 逐个处理按键。

### 5. readKey：解析按键

```go
func readKey() int {
    buf := make([]byte, 1)
    os.Stdin.Read(buf)
    if buf[0] != 27 {  // 不是 ESC
        return int(buf[0])
    }
    // ESC 序列：可能是方向键
    os.Stdin.Read(buf[:2])
    // 方向键: ESC [ A/B/C/D
    if buf[0] == '[' {
        switch buf[1] {
        case 'A': return UpKey
        case 'B': return DownKey
        case 'C': return RightKey
        case 'D': return LeftKey
        case 'H': return HomeKey
        case 'F': return EndKey
        }
    }
    return EscKey
}
```

终端的方向键发送的是 3 字节序列（`ESC [` 后跟字母），`readKey` 识别这些序列并映射为内部常量。

## ChatUI 层：把 Agent 装进终端

### 核心设计：行式追加，非全屏重绘

```go
type ChatUI struct {
    agent *agent.Agent
}

func NewChatUI(ag *agent.Agent) *ChatUI {
    return &ChatUI{agent: ag}
}

func (ui *ChatUI) Run(ctx context.Context) error {
    raw, _ := EnterRawMode()
    defer raw.Restore()

    // 欢迎信息
    fmt.Println(Green("🤖 Pi Agent v0.1.0"))
    fmt.Println(Gray("输入消息后按 Enter，Ctrl+C 退出"))
    fmt.Println()

    for {
        fmt.Print(Cyan("> "))
        input, ok, err := EditLine(Cyan("> "), "")
        if !ok || err != nil {
            break  // Ctrl+C 退出
        }
        if strings.TrimSpace(input) == "" {
            continue
        }

        // 回显用户输入
        fmt.Println(Cyan("\n💬 You:"), input)
        fmt.Print(Green("🤖 Assistant: "))

        // 调用 Agent，流式消费事件
        stream := ui.agent.Run(ctx, input)
        for event := range stream {
            switch event.Type {
            case agent.EventTextDelta:
                fmt.Print(event.Delta)  // 实时打印，无缓冲

            case agent.EventToolCall:
                fmt.Print(Gray("\n  [调用工具: " + event.ToolCall.Name + "]"))

            case agent.EventToolResult:
                result := event.Result
                if len([]rune(result)) > 100 {
                    result = string([]rune(result)[:100]) + "..."
                }
                fmt.Print(Gray("\n  [工具结果: " + result + "]"))

            case agent.EventDone:
                if event.Usage != nil {
                    total := formatTokens(event.Usage.TotalTokens)
                    fmt.Print(Gray("\n  [" + total + " tokens]"))
                }
                fmt.Println()

            case agent.EventError:
                fmt.Println(Red("\n✖ " + event.Error.Error()))
            }
        }
        fmt.Println()
    }

    fmt.Println(Gray("\n再见！"))
    return nil
}
```

### 流式渲染：打字效果

关键代码：

```go
case agent.EventTextDelta:
    fmt.Print(event.Delta)  // 无缓冲，直接写入
```

每收到一个 `EventTextDelta`（可能只有一个字），立即 `fmt.Print`。不需要 flush——`fmt.Print` 写到终端时终端本身就在逐字渲染。

### 角色标记

| 角色 | 颜色 | 前缀 |
|------|------|------|
| 用户 | 青色 | `💬 You:` |
| AI | 绿色 | `🤖 Assistant:` |
| 工具调用 | 灰色 | `[调用工具: xxx]` |
| 工具结果 | 灰色 | `[工具结果: ...]`（100 字截断） |
| 错误 | 红色 | `✖` |

## 为什么不使用第三方 TUI 框架？

社区有优秀的框架如 [bubbletea](https://github.com/charmbracelet/bubbletea) 和 [tview](https://github.com/rivo/tview)。不使用的理由：

1. **依赖最小化**：项目原则是能用标准库就不用三方包
2. **需求简单**：pi-agent 只需要"对话终端"，不需要多窗口/组件树
3. **学习价值**：手动实现 ANSI/raw mode 是理解终端底层的好机会
4. **行式追加优于全屏重绘**：对话是"滚动"的，不需要像 vim 一样重绘整个屏幕

## 思想总结

| 思想 | 体现 |
|------|------|
| **分层设计** | Terminal（底层能力）→ ChatUI（业务 UI） |
| **标准库优先** | syscall/termios/ANSI 全手工实现，零三方依赖 |
| **行式追加** | 对话像真实终端，只追加不重绘 |
| **实时流式** | EventTextDelta 直写终端，无缓冲打字效果 |
| **阻塞式交互** | EditLine 阻塞等待用户输入，简化调用方逻辑 |
