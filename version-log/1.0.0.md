## 发版说明

### 基础库
- 日志库 `lg`：Writer 接口 + Router 路由 + ConsoleWriter/FileWriter/MultiWriter，模块化 Logger
- 日志扩展：LevelDir 分级目录、Retention 定时清理、RotateBySize/RotateByInterval 切割、LogNamePattern 文件名构建器
- `SetPath()` 一行完成 FileWriter 创建 + SetDefault + 分级配置

### AI 层 — 多 Provider 统一接口
- `Provider` / `Model` 接口，`Message` / `Context` / `ToolDefinition` / `ToolCall` 类型体系
- 流式事件模型：`Event` + `Stream` channel（text delta / tool call / usage）
- OpenAI Provider（Chat Completions + SSE 流式 + 工具调用）
- Anthropic Provider（Claude Messages API + SSE）
- Google Provider（Gemini API + alt=sse）
- my-openai Provider（本地 OpenAI 兼容模型，如 qwen/lm-studio/ollama）

### Agent 运行时
- 工具调用循环（LLM → 工具调用 → 注入结果 → LLM），最大步骤限制
- 事件系统：`agent.Event` + `agent.Stream`
- `Continue()` / `Reset()` / `Messages()` / Session 持久化（JSONL）

### Tool 系统
- File Tool 组：`read_file` / `write_file` / `list_dir` / `search_file`（AllowedRoots 白名单）
- Shell Tool：白名单/黑名单/30s 超时

### TUI 层
- `LineEditor` 多行编辑器：多行输入、历史记录（↑↓）、`Ctrl+L` 清屏、`Tab` 路径补全
- 语法高亮：Go / Python / JS / Shell / JSON / YAML
- Markdown 渲染：标题、粗体、斜体、代码、列表 → ANSI 终端样式
- `ChatUI` 交互式对话：事件流渲染、对话内命令（`/clear` `/reset` `/export` `/help`）

### CLI 产品
- 命令路由：`pg {chat|config|version|help}` + `--prompt` 单次模式
- YAML 配置文件（三级优先级：命令行 > 环境变量 > 配置文件 > 默认值）
- Emoji 可插拔主题系统（default/minimal/monochrome + 自定义注册）
- 日志分级存储（info/error 分目录，不污染终端）
- Windows 交叉编译支持（build tag 隔离 TUI）

### 构建 & 发布
- goreleaser 自动构建 + GitHub Release
- Makefile 统一命令入口（build/pack/release/test/lint）
- `install.sh` 一键安装（OS/Arch 检测，无需 Go 环境）
- `pack.sh` 本地手动打包
