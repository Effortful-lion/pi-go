# v1.0.0

更新时间：2026-07-28

### 发版内容

#### 基础库
- 日志库 `lg`：Writer 接口 + Router 路由 + ConsoleWriter/FileWriter/MultiWriter，支持模块化 Logger 和包级便捷函数
- 工程组织：go.mod、目录结构、AGENTS.md 开发准则

#### AI 层 — 多 Provider 统一接口
- `ai.Provider` / `ai.Model` 接口：统一多提供商 LLM 调用抽象
- `ai.Message` / `ai.Context` / `ai.ToolDefinition` / `ai.ToolCall` 类型体系
- 流式事件模型：`ai.Event` + `ai.Stream` channel，支持 text delta、tool call、usage 等事件
- OpenAI Provider：实现 OpenAI Chat Completions API（SSE 流式，支持工具调用）
- Anthropic Provider：实现 Claude Messages API（SSE，content_block / input_json_delta 映射）
- Google Provider：实现 Gemini API（alt=sse 模式，systemInstruction / functionDeclarations 映射）

#### Agent 运行时
- `Agent` 核心：工具调用循环（LLM → 工具调用 → 注入结果 → LLM 继续），最大步骤限制
- 状态管理：`Config` 配置结构体，对话历史（messages）管理
- 事件系统：`agent.Event` + `agent.Stream`，暴露步骤/文本/工具调用/工具结果/错误事件
- `Continue()`：在现有对话基础上继续（可选注入额外上下文）
- `Reset()`：清空对话历史，保留 system prompt
- `Messages()`：返回对话历史快照（只读）
- Session 持久化：JSONL 格式，`SaveSession` / `LoadSession` / `ListSessions` / `DeleteSession`

#### Tool 系统
- `tool.Tool` 接口：`Name()` + `Definition()`（JSON Schema）+ `Execute()`
- File Tool 组（`read_file` / `write_file` / `list_dir` / `search_file`）
  - `read_file`：分页读取（offset/limit），行号标注，最大 1MB
  - `write_file`：创建/覆盖写入，自动创建父目录
  - `list_dir`：目录列表，`d` 前缀标记目录
  - `search_file`：通配符模式递归搜索
  - 安全：`AllowedRoots` 白名单 + 符号链接解析
- Shell Tool（`shell`）：`command` + `cwd` 参数
  - `AllowedCommands` 白名单、`BlockedPatterns` 黑名单（rm -rf/sudo/chmod 777/curl\|sh/wget\|sh）
  - 30s 超时，`exec.CommandContext`

#### TUI 层 — 终端 UI
- 终端原语：原始模式开关、光标控制、ANSI 颜色/样式、清屏
- `LineEditor` 多行编辑器
  - 多行输入：`Alt+Enter` 在光标处拆行，`←→↑↓` 多行导航，`Backspace` 行首合并
  - 历史记录：`↑↓` 浏览，自动去重/裁剪（1000 条上限），浏览中途按键退出并恢复编辑内容
  - `Ctrl+L` 清屏并重绘
  - `Tab` 文件路径补全：自动完成，多候选取公共前缀
  - `Ctrl+←→` 按单词跳转
  - 兼容旧版 `EditLine` API
- 语法高亮：支持 Go / Python / JS / Shell / JSON / YAML 6 种语言，无三方依赖
- Markdown 渲染：标题、粗体、斜体、行内代码、代码块、列表、引用、表格 → ANSI 终端的语义化格式
- `ChatUI` 交互式对话界面
  - `Run()` 主循环，事件流渲染（文本增量、工具调用、错误）
  - 对话内命令：`/clear` `/reset` `/export` `/help`
  - `ExportConversation`：导出完整对话为 Markdown

#### CLI 产品
- 命令路由：`pi {chat|config|version|help}`
- 多 Provider 切换：`-provider openai|anthropic|google`
- 配置管理：YAML 配置文件（`~/.pi-go/config.yaml`），三级优先级：命令行 > 环境变量 > 配置文件 > 默认值
- `config init/show/set` 子命令
- 版本号 0.2.0
