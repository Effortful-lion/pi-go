## 2026-08-01

### my-openai provider 修复
- 修复 `stream_able` → `stream`：JSON 字段名错误导致本地 OpenAI 兼容模型不返回流式响应
- `OpenAIRuquest` 中 `MaxTokens`/`Temperature` 添加 `omitempty`，避免零值发送到 API

### max_tokens 默认值改进
- `chat.go`：MaxTokens 未配置时自动从 `prov.Models()` 获取模型最大值，不再需要用户手动配置
- `config.go`：`PiConfig.MaxTokens` 添加 `omitempty`，零值不写入配置文件
- `config_cmd.go`：`config init` 不设置 max_tokens，配置文件中以注释示例展示可选配置项（`base_url`/`system_prompt`/`max_tokens`/`temperature`/`max_steps`）
- `config_cmd.go`：`config set provider/model` 不再自动更新 MaxTokens，由运行时自动获取

### API key 错误提示优化
- `chat.go`：API key 未设置时的错误信息改为分条列出 3 种设置方式，每种附具体命令示例

### 日志落盘

  - `.Module()` / `.Date(layout)` / `.Clock(layout)` / `.Timestamp()` / `.Char(s)` 最小片段

- `lg/writer.go`：新增 `NewFileWriterWithLogName(dir, level, logName)`，支持动态文件名自动切分
- `lg/logger.go`：新增 `SetPath(dir, level, pattern, opts...)`，一步完成日志路径设置
- `lg/logname_test.go`：10 个测试覆盖所有组合模式 + 文件切换 + 自定义路径，全部通过

### 日志库扩展计划
- `docs/日志库扩展计划.md`：5 项可插拔扩展能力规划
  - LevelDir（默认）：自动按 debug/info/warn/error/fatal 分目录
  - RotateByInterval/RotateBySize：定时/定大小切割
  - Retention：定时清理过期日志
  - LevelPriority：高优先级日志出现时屏蔽低优先级

### lg 库：LevelDir 分级目录（LogOption 模式）
- `lg/logger.go`：新增 `LogOption` 类型和 `logConfig` 结构体，统一扩展入口
- `lg/logger.go`：新增 `WithLevelDir(level, dir)`，将指定级别日志输出到独立子目录
- `lg/logger.go`：`SetPath` 签名改为 `SetPath(dir, level, pattern, opts ...LogOption)`
  - 无 opts：单个 FileWriter，不分级
  - 有 WithLevelDir：MultiWriter 组合默认 FileWriter + 各子目录 FileWriter，按 level 过滤
- `lg/logger_test.go`：新增 3 个测试（不分级/分级/级别过滤），全部通过

### lg 库：LevelPriority 废弃
- `SetPath` 的 `level` 参数已覆盖级别过滤需求，无需额外实现
- `docs/日志库扩展计划.md`：LevelPriority 标记为已废弃

### lg 库：Retention 定时清理
- `lg/logger.go`：新增 `WithRetention(maxAge)`，保留时长内不过期，超过即删除
- `lg/logger.go`：新增 `startRetention(dir, maxAge)`，启动后台 goroutine，检查间隔 = min(maxAge, 1h)
- `lg/logger.go`：新增 `cleanDir(dir, maxAge)`，递归清理目录中超过 maxAge 的 .log 文件，不删非 .log 文件
- `lg/logger_test.go`：新增 3 个测试（清理旧文件/保留新文件/子目录清理），全部通过
- `lg/logger.go`：新增 `WithRotateBySize(size)`，超过 size 字节时自动切新文件
- `lg/writer.go`：`FileWriter` 新增 `rotateSize`/`written`/`seq` 字段，`Write` 中累计字节数超阈值时递增序号并切换
- `lg/writer.go`：新增 `insertSeq(name, seq)`，在 `.log` 前插入 `.001` 等三位补零序号
- 可与 RotateByInterval 组合使用
- `lg/logger_test.go`：新增 2 个测试（切换/序号格式），全部通过
- `lg/logger.go`：新增 `WithRotateByInterval(d)`，在 pattern 末尾自动追加日期+时钟

  - >= 1小时 → `pg_2026-08-01_12-00.log`（分钟精度）
  - >= 1天 → `pg_2026-08-01.log`（天精度）
- `lg/logger.go`：新增 `intervalLayout(d)` 辅助函数
- 不依赖 goroutine，纯文件名策略：每次 Write 时 FileWriter 检测文件名变化自动切换
