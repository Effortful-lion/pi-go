### Agent 运行时层：事件系统
- 新增 `agent/event.go`：定义 AgentEventType 枚举（StepStart/StepEnd/ToolCall/ToolResult/TextDelta/Done/Error）、Event 结构体、Stream 类型
- AgentEvent 比 ai.Event 更高层，带有运行时语义（Step 编号、Tool 进展）

### Agent 运行时层：核心循环
- 新增 `agent/agent.go`：Agent 结构体 + Run 方法，实现 LLM ↔ 工具调用自动循环
- 核心逻辑：用户消息入队 → 调用 LLM → 收集文本/工具调用 → 执行工具 → 注入结果 → 循环，直到 LLM 无工具调用或超限
- 对话历史 (`messages []ai.Message`) 内置管理，支持多轮对话
- goroutine + channel 异步架构，与 AI 层 Stream 模式一致
- 配置项：Provider, ModelID, SystemPrompt, Tools, MaxSteps, Temperature, MaxTokens
- 工具执行失败不中断循环，将错误信息作为 ToolResult 注入历史

### TUI 层：终端底层
- 新增 `tui/terminal.go`：原始终端控制 + ANSI escape 封装
- Raw Mode：通过 `syscall` + `termios` 实现（EnterRawMode/restore），支持 macOS
- 光标控制：CursorUp/Down/Forward/Back/MoveTo/Hide/Show（8 个函数）
- 屏幕控制：ClearLine/ClearLineFromCursor/ClearScreen/LineStart
- 颜色样式：Color 枚举（8 色+灰）、Style 结构体（Fg/Bold/Dim/Italic/Underline）、StyleText 函数
- 便捷样式：Bold/Dim/Red/Green/Blue/Cyan/Gray/Yellow 8 个快捷函数
- 行编辑：EditLine 函数，支持单行文本编辑（← → Home End Backspace Delete Enter Ctrl+C Ctrl+D Ctrl+← → 跳词）
- 键盘读取：readKey 解析单字符按键和 ANSI 转义序列

### TUI 层：交互式对话 UI
- 新增 `tui/chat.go`：ChatUI 结构体，封装 Agent 对话交互流程
- Run 方法：进入 raw mode → 欢迎信息 → 循环（提示符→读取输入→agent.Run→流式渲染）→ 退出后恢复终端
- 流式渲染策略：行式追加（非全屏重绘），EventTextDelta 直接写入终端实现打字效果
- 角色标记：💬 You（青色）、🤖 Assistant（绿色）、[调用工具]（灰色）、[工具结果]（灰色，100字截断）
- Usage 统计显示：≥1000 tokens 显示为 "1.2k tokens"，<1000 显示精确数字
- 错误处理：红色 ✖ + 错误信息
