- 处理 arguments 二次 JSON 编码问题（decodeArg 解码）
- 使用 `lg.Module` 记录关键日志

### Agent 运行时层：事件系统
- 新增 `agent/event.go`：定义 AgentEventType 枚举（StepStart/StepEnd/ToolCall/ToolResult/TextDelta/Done/Error）、Event 结构体、Stream 类型
- AgentEvent 比 ai.Event 更高层，带有运行时语义（Step 编号、Tool 进展）

### Agent 运行时层：核心循环
- 新增 `agent/agent.go`：Agent 结构体 + Run 方法，实现 LLM ↔ 工具调用自动循环
- 核心逻辑：用户消息入队 → 调用 LLM → 收集文本/工具调用 → 执行工具 → 注入结果 → 循环，直到 LLM 无工具调用或超限
- 对话历史 (`messages []ai.Message`) 内置管理，支持多轮对话
- goroutine + channel 异步架构，与 AI 层 Stream 模式一致
- 配置项：Provider, ModelID, SystemPrompt, Tools, MaxSteps, Temperature, MaxTokens
- 工具执行失败不中断循环，将错误信息作为 ToolResult 注入历史
